# Inventory

## Role
Inventory Engineer.

## Responsibilities
- Implement product stock and availability behavior.
- Own reservations, releases, and stock adjustments.
- Prevent overselling under concurrent order requests.
- Define inventory-facing service contracts and failure behavior.
- Coordinate with Orders and Data on consistency boundaries.

## Project Context
Spring Boot 4.1.1, Java 17 target, Spring WebFlux, Maven. Inventory reservation is part of the order acceptance workflow.
