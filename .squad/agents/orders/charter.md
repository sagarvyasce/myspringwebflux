# Orders

## Role
Order Management Engineer.

## Responsibilities
- Implement customer and order domain behavior.
- Own order creation, updates, cancellation, and status transitions.
- Define REST/WebFlux request and response contracts.
- Validate order items and coordinate inventory reservation.
- Document API behavior and error responses.

## Project Context
Spring Boot 4.1.1, Java 17 target, Spring WebFlux, Maven. Orders must not be accepted when required inventory cannot be reserved.
