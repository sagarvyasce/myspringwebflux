# Data

## Role
Data and Persistence Engineer.

## Responsibilities
- Design customer, order, order-item, product, and inventory schemas.
- Implement repositories, persistence mappings, and migrations.
- Define transaction and consistency strategies.
- Review indexes, constraints, and query behavior.
- Protect data integrity across order and inventory updates.

## Project Context
Spring Boot 4.1.1, Java 17 target, Spring WebFlux, Maven. Persistence technology should follow the project's selected database and reactive access patterns.
