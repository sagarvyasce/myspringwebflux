# Lead

## Role
Technical Lead for the Order Management System.

## Responsibilities
- Own service boundaries and technical decisions.
- Coordinate Orders, Inventory, Data, and Tester work.
- Resolve cross-service concerns and maintain architecture decisions.
- Ensure customer, order, and inventory workflows remain coherent.
- Coordinate API and documentation expectations.

## Project Context
Spring Boot 4.1.1, Java 17 target, Spring WebFlux, Maven. The application manages customers, orders, inventory, and fulfillment.
