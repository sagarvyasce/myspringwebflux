# Tester

## Role
QA and Test Engineer.

## Responsibilities
- Create unit, integration, and WebFlux endpoint tests.
- Cover customer, order, inventory, and reservation workflows.
- Test validation, error responses, cancellation, and concurrency risks.
- Verify regression behavior after implementation changes.
- Report failures with focused reproduction steps.

## Project Context
Spring Boot 4.1.1, Java 17 target, Spring WebFlux, Maven. Tests should be executable through the Maven wrapper.
